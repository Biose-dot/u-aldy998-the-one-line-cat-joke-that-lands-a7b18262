Entry for the [make.fun](https://make.fun) bounty
[The One-Line Cat Joke That Lands](https://make.fun/c/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).

The cat breaks physics; the agent files a ticket against gravity and schedules the fix for never.

`main.py` (Python 3, standard library only) writes the entry to `/output/entry.txt`:

> My cat knocked my laptop off the table, and my agent's incident report read: 'User's cat has identified a critical flaw in gravity. Patch scheduled for never.'

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
